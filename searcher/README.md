# Searcher

Сервис поиска новых эквайеров на базе SearXNG.

Ищет публичные эквайринговые решения через метапоисковые движки,
парсит результаты и складывает кандидатов в БД для fmatch.

## Запуск (локально)

```bash
# Используем апстрим-образ с кастомным конфигом
docker compose up -d searcher
```

## Обрезка апстрима

Исходники SearXNG лежат в `../searxng/` (отдельный репозиторий).
Задача — вырезать из апстрима ненужные движки и UI, оставив только
 searcher-friendly движки (Yandex, Google, Bing, Brave и т.д.) и
JSON-вывод.
