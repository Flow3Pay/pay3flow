# Проверка криптопар через фронтенд — 18 октября 2026

## Что проверено

На production `https://pay3flow.lefine.pro` открыта новая браузерная сессия.
Активы и сети выбирались кликами в обоих этапах picker; перед сменой пары
сумма обнулялась, затем вводилась нужная сумма. Проверены запросы WebSocket,
завершённые результаты, число реально отрисованных карточек и скриншоты.
Кошелёк не подключался; обмены не выполнялись.

## Найденные пропуски

### GRAM искали под старым тикером

Production запрашивал `TON` и соединял спотовые рынки по `TONUSDT`.
Живые `GRAMUSDT`/`GRAM_USDT` с положительными bid/ask подтверждены на
Binance, Bybit, OKX, Bitget, MEXC и Gate.
[Ответы шести публичных API](audits/browser-crypto-2026-10-18/gram-spot-probes.json).

Один результат в строках TON — только спотовая оценка Whitebird: этот адаптер
уже запрашивал GRAM, но переименовывал результат обратно в TON. При первом
прогоне часть этих направлений возвращала ноль. Такой результат не подтверждает
доступность вывода монеты на выбранной сети.

В BestChange парсер нативных сетей не распознавал название GRAM. В Symbiosis
нативная сеть TON была в каталоге, но отсутствовал preview-адрес TON, из-за
чего `supports_pair` исключал её ещё до запроса. После добавления адреса
отдельный публичный quote-запрос ETH→GRAM/TON всё же вернул `No route available
right now`: отсутствие маршрута у самого провайдера нельзя исправить названием.
[Проверенный запрос и отказ Symbiosis](audits/browser-crypto-2026-10-18/symbiosis-native-gram.json).
NEAR Intents в браузерных проверках также отвечал, что котировка пары недоступна.

### Промежуточные активы брались из короткого общего списка

Даже для ETH→BTC искались не все доступные двухшаговые спотовые пути.
Для Gate с положительными bid/ask обнаружены общие рынки через:

`ASTR, CRV, FIL, GT, GUSD, RLUSD, USD1, USDC, USDT`.

Семь первых активов отсутствовали в списке `assets_searched` обычного запроса.
Пути ETH→ASTR→BTC и аналогичные не доходили до составления маршрута.
[Проверка графа реальных рынков Gate](audits/browser-crypto-2026-10-18/gate-market-graph.json).
Для ETH→AVAX в том же снимке общими промежуточными рынками были USDC/USDT,
для ETH→DOT — BTC/USDC/USDT; этот конкретный пропуск там не подтвердился.

## Изменения в рабочей копии

- Основная монета теперь `GRAM`, нативная сеть — прежняя `ton` / `TON`.
  Стабильный ID карточки `global-ton` сохранён для ранее выбранных методов.
  Старые `#/swap/ETH/TON` ссылки преобразуются в выбор GRAM/TON; старый
  `TON` в запросе маршрута также принимается как прежний тикер монеты.
- Обновлены каталоги сетей и карточек, цена к USD, default assets,
  BestChange, NEAR Intents, Symbiosis, Whitebird и Papa Change.
  Для Symbiosis добавлен только preview-адрес TON; это не включает новую
  возможность подписывать TON-транзакции.
- Отдельные токены с тикерами TON/GRAM не подменяют нативную монету:
  для EVM-представлений используются проверенные адреса контрактов, для NEAR
  — идентификатор нативного актива. Посторонние одноимённые jetton исключаются.
- Иконка скачана по предоставленной пользователем ссылке
  `https://images.cryptorank.io/coins/gram_prev_toncoin1780667335325.png`
  (для скачивания использован параметр `?width=128`; ответ — PNG 400×400).
  Она хранится локально как `static/icons/assets/gram.png`, без внешнего
  запроса при каждом открытии формы. Значок и название сети TON сохранены.
- Если промежуточные активы не заданы явно, спотовый поиск дополняет список
  общими соседями исходного и целевого актива из тикеров выбранной площадки.
  Явный пользовательский фильтр промежуточных активов сохраняется. Фиатные
  остатки не добавляются как криптопереходы; нулевые, нечисловые и crossed
  bid/ask отбрасываются.

[Локальная форма GRAM/TON на десктопе](audits/browser-crypto-2026-10-18/local-gram-chromium.png).
[Локальная форма на мобильном](audits/browser-crypto-2026-10-18/local-gram-mobile.png).

## Пределы проверки

Полное покрытие всего рынка не доказано. Проверены конкретные пары и суммы,
зарегистрированные источники и пути в пределах алгоритма. Не перебирались
произвольные цепочки любой длины или все существующие биржи.
Для склеенных спотовых тикеров разделение base/quote использует реестр
поддержанных котируемых активов. Неизвестный quote asset может потребовать
добавления в реестр или загрузки явных base/quote метаданных площадки.

Спотовые пути остаются оценками: глубина стакана, доступность и комиссия
ввода/вывода на конкретной сети не подтверждены. Разные пути и агрегаторы
могут использовать одну ликвидность; их нельзя складывать в объём OTC.
Cifra продолжает отвечать невалидным JSON, а часть quote API отклоняет
пары или суммы. Эти ошибки сохранены в статусах аудита.

Изменения локальные и не развёрнуты в production. Таблица выше описывает
production до исправлений; увеличение числа живых маршрутов после выкладки
ещё не измерено.

## Повторение проверки

```sh
cd pay3low-svelte-frontend
PAY3FLOW_AUDIT_LEGACY_TON=1 PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium \
  node tests/live-crypto-audit.mjs https://pay3flow.lefine.pro /tmp/browser-crypto-audit/results.json
```

Скрипт открывает новую сессию и кликает элементы формы. Он не соединяет
кошелёк и не нажимает подтверждение обмена. Для версии с переименованием
нужно убрать `PAY3FLOW_AUDIT_LEGACY_TON=1`: по умолчанию сценарии используют GRAM.
